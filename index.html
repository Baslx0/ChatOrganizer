About

What this project does

Chat Organizer turns a ChatGPT data export into an auditable organization plan. It is intentionally local-first: import, classify, review, then export a plan for an optional executor.

Design principles

  • No server upload required.
  • No automatic deletion.
  • Every suggested action is editable.
  • Browser automation is isolated from analysis.
  • Project rules are transparent and user-editable.
  • Agent mode supports semantic, evidence-backed organization through a portable SKILL.md and local CLI.
